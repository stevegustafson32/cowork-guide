CHANGE LOG · UPDATED OCTOBER 2026

What Changed

Claude changes most months. This page lists each change, the day Anthropic announced it, and which guides were revised for it. Every entry links to the source.

October 1, 2026

Claude Code mods

Small TypeScript functions, shipped inside plugins, that change how Claude Code works. Anthropic's own words: they run with the same access to your machine as Claude Code itself and are not sandboxed, so install them only from sources you trust.

Source: claude.com · Guide updates in progress.

September 28, 2026

Claude Sonnet 5.5

Replaces Sonnet 5 as the faster, lower-cost complement to Opus 5.5. Anthropic positions it for well-scoped everyday tasks and polished documents, with Opus 5.5 stronger on complex, open-ended work.

Source: anthropic.com · Updated in: Claude Beginner.

September 28, 2026

Claude Code starts in auto mode

From version 2.1.284, interactive terminal and VS Code sessions start in auto mode when no permission mode is configured. Plan Mode is still there; it is no longer where a new session begins.

Source: code.claude.com · Guide updates in progress.

September 25, 2026

Plugin directory submission portal

Developers on paid plans can submit a plugin (a GitHub repo of skills, connectors or both) to the Claude directory. Each submission is validated and safety-scanned, then reviewed. Published plugins get install and search analytics.

Source: claude.com · Updated in: Claude Advanced.

September 23, 2026

Claude Marketplace

One place to find plugins and connectors (more than 2,000), Claude-powered products from partners, and service partners.

Source: claude.com · Updated in: Claude Beginner, Claude Advanced.

September 22, 2026

Claude Opus 5.5

Replaces Opus 5. Anthropic says it performs at the level of Fable 5.1 on most work at a lower price than Opus 5. Five-hour usage limits went up on Pro, Max and Team.

Source: anthropic.com · Updated in: Claude Beginner, Claude Design, The Prompting Guide.

September 16, 2026

Cowork and chat are one Claude

You no longer choose between Chat and Cowork before starting; what Cowork could do is available from any conversation. Local folders, the built-in browser and computer use still need Claude Desktop. The permission setting in the message box is Manual (the default, asks before each action) or Auto. Cowork's Global instructions are now Instructions for Claude in Settings > General. Existing tasks, projects, connectors and skills carry over. Rolling out to Pro and Max first; Team and Free follow; Enterprise gets 30 days' notice. Claude Docs and Claude Slides launched in beta on paid plans, and Claude Design works inside any conversation.

Source: claude.com · Updated in: Claude Beginner, Claude Advanced, Claude Everywhere, Claude Code 2.0, Claude Design, Claude in Office, Claude Writing, The Prompting Guide, Claude in Action.

September 15, 2026

Claude for Small Business adds 43 workflows

The plugin now ships 43 workflows and 27 new integrations, including Monday Brief, Speed to Lead, Proposal Builder, Social Content Engine and Close the Month. Every workflow starts in approval mode. Available on every paid plan.

Source: claude.com · Guide updates in progress.

September 1, 2026

Claude Fable 5.1

Replaces Fable 5 as the most capable model. Anthropic's model page dates it September 2026; the app release notes say September 1.

Source: anthropic.com · Updated in: Claude Beginner, The Prompting Guide.

August 26, 2026

Claude in Chrome is generally available

On every paid plan. Chrome only: no other Chromium browsers, no mobile. Claude now approves actions it judges safe on its own, using the same mechanism as auto mode in Claude Code; you can switch back to manual approval in settings. A classifier checks each action against what you asked for and blocks mismatches.

Source: claude.com · Guide updates in progress.

August 26, 2026

The desktop app has its own browser

A browser opens in the side panel when a task needs a website. It is Claude's browser, separate from yours; you bring logins over site by site, and banking, email and single sign-on sites are excluded unless you include them. Pro, Max and Team. If you already use Claude in Chrome, that stays the default.

Source: claude.com · Guide updates in progress.

August 25, 2026

Memory works across chat and Cowork

Memory now carries between chat and Cowork in the cloud. You can edit or delete Topics in Settings > Memory. On by default for Free, Pro and Max; off by default for Team and Enterprise.

Source: support.claude.com · Updated in: Claude Advanced, Claude Beginner.
